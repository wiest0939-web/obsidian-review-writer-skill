# Obsidian Review Writer Skill

A Codex skill for evidence-first literature review writing using Obsidian as an auditable reading-note and evidence-matrix workspace.

## Features

- Initialize and continue a reading queue from local PDFs
- Create structured close-reading notes in an Obsidian vault
- Maintain an evidence matrix
- Draft review sections from validated evidence
- Audit manuscript claims against source literature
- Support high-level medical review workflows, including hepatology review preparation

## Installation

Clone or download this repository.

Copy the `obsidian-review-writer` folder into your Codex skills directory:

```powershell
Copy-Item -Recurse .\obsidian-review-writer "$env:USERPROFILE\.codex\skills\"
